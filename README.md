My landing page went well, now I think it's time to test my ability to learn and apply new skills.

Up to this point I've not been familiar with Responsive Web Design or how to implement it. That changes now. This project's main focus is to make a funny little cafe website that is responsive, built mobile-first and adapts to wider screens through media queries, while also using responsive units for sizing text and other elements on the pages. It will have a navigation bar for the desktop, and a form fillable for email contact, as I haven't really messed with forms much.

It will also be the first website I've done with multiple pages.
